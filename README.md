# File Counter 📄

## About
A simple Python project that counts the number of lines, words, and characters in a text file.

## Features
- Uploads a file using Google Colab.
- Reads the file content.
- Counts lines, words, and characters.
- Displays the results.

## Concepts Used
- File handling
- `len()`
- `split()` and `splitlines()`
- Variables

## What I Learned
I learned how to read a text file and count its lines, words, and characters using Python.
